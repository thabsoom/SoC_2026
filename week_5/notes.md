# Exploratory Data Analysis (EDA) 

## Topics Covered
- Introduction to Exploratory Data Analysis (EDA)
- Data Cleaning techniques
- Understanding dataset structure using Pandas
- Descriptive statistics (`describe()`, `info()`)
- Checking for missing values (`isnull()`, `sum()`)
- Handling missing data (drop/fill methods)
- Detecting duplicate records
- Understanding data types and converting them when necessary
- Identifying outliers using Box Plots and the IQR method
- Basic visualization using Matplotlib and Seaborn
  - Histogram
  - Box Plot
  - Violin Plot
  - Count Plot
- Understanding distributions and relationships between variables

## Key Learnings
- EDA is the first step in understanding a dataset before applying machine learning models.
- Data cleaning is essential to improve data quality and model performance.
- Visualizations help identify trends, distributions, missing values, and outliers.
- Summary statistics provide a quick overview of numerical features.
- The IQR method can be used to detect potential outliers.
- Different plots serve different purposes:
  - Histogram → Distribution of a numerical feature
  - Box Plot → Spread of data and outlier detection
  - Violin Plot → Distribution along with density
  - Count Plot → Frequency of categorical variables
